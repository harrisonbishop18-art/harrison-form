# FORM

Personal training, food, shoulder and knee-rehab tracking app for Harrison.

## Included
- 3-day strength plan with shoulder-aware exercise choices
- Core work built into training
- Weekly Sunday-style check-in without body measurements or sleep/recovery questionnaires
- Knee rehab tracker for exercises prescribed by the user's clinician
- Meal photo logging
- Typed food logging
- Browser voice-to-text food logging
- Training weights and reps history with progression guidance
- Weekly stretching and optional Pilates

## Important limitation
This static app stores data in the browser. A direct Apple Health/HealthKit sync or live ChatGPT conversation inside the app requires a separate authenticated backend/integration and cannot be created simply by placing an OpenAI API key in a public browser app.
